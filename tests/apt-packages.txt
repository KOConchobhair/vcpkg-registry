# environments cannot drift.
#
# No cmake or ninja on purpose: Ubuntu 22.04 ships cmake 3.22 and vcpkg at this
# baseline needs 4.2+ for string(JSON ... STRING_ENCODE). vcpkg carries cmake
# 4.4.0 for linux-aarch64 and linux-x86_64 both, so let it fetch its own and do
# not set VCPKG_FORCE_SYSTEM_BINARIES.
